Limitations on Mobile: iOS blocks spawning shells. Use flutter_pty for Android + macOS. For iOS, you’ll need to SSH to a remote Linux box or use a web-based terminal via flutter_inappwebview pointed at your server.

Workaround for iOS:
// SSH to your dev machine
final client = SSHClient(
  await SSHSocket.connect('your-server.com', 22),
  username: 'user',
  onPasswordRequest: () => 'password',
);
final shell = await client.shell();
terminal.onOutput = (data) => shell.write(const Utf8Encoder().convert(data));
shell.stdout.cast<List<int>>().transform(Utf8Decoder()).listen(terminal.write);

Security: The terminal has full access to your system. Sandbox with chroot or run in Docker if you’re worried.
